Architecture boundary

WebSocket → Fargate → AppSync → React≠Historical REST → Lambda → S3 → Glue → ML→Aurora predictions → React

The live tick stream is not written to Aurora. Daily historical candles are separately collected from Upstox REST, kept in S3 for training, and appended incrementally. Aurora stores watchlists, forecasts, recommendations and outcomes, not routine tick history.

Scope note

The uploaded reference pages currently use a 50-stock / 5–6-year pilot. This tracker reflects the newer target of up to 15 years and a scalable NSE universe. Start with 5–10 pilot stocks, verify source availability and licensing, and then backfill further; not every instrument has 15 years of history.
